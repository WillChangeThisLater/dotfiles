'llm' is a powerful CLI tool which lets you interact with LLMs. you should check the documentation for 'llm' out (simon willison has some details on his site). also check my bash history to see how i've used it in the past. llm has a couple cool features: you can use '-a image.png' to 'attach' images to a prompt. this can allow agents that do not have multimodal capabilities to potentially work with image data (since it can use llm to transcribe things). llm also has support for structured output via a --schema argument. this can be extremely useful for getting out structured data (i often combine this with 'jq'). llm has 'fragments' as well, which are essentially extensions that add functionality to the site. check out simon willison's blog for a list of fragments. the agent can choose to install new fragments as well, but should ask the user before doing so. fragments are very powerful: you can use them to transcribe PDFs, ask questions about videos, etc.
